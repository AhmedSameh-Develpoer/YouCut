# YouCut — تصميم حفظ المشروع والتعافي المحلي

الحالة: مسودة تقنية؛ قرارات امتداد الملف ومجلد النسخ الاحتياطي ومجلد البيانات والحفظ والاسترداد معتمدة، وتفاصيل التنفيذ والكاش بانتظار التحقق التقني.

## الهدف

حفظ المشروع في ملف `.youcut` بصيغة JSON، مع مجلد بيانات ملاصق له. يحفظ التطبيق تعديلات المستخدم تلقائيًا، ويتيح استعادة العمل بعد إغلاق مفاجئ، مع بقاء ملفات الفيديو المحلية الأصلية في أماكنها.

## فصل أماكن الحفظ

هناك ثلاثة أماكن مستقلة: ملف `.youcut` الذي يختاره المستخدم عند إنشاء المشروع أو حفظه؛ مجلد `.youcut-data` المجاور للملف، ويضم التنزيلات الخاصة بالمشروع والكاش؛ ومجلد النسخ الاحتياطي الذي يختاره المستخدم من الإعدادات ويحفظ فيه التطبيق نسخ JSON وحالات الاسترداد. تغيير مجلد النسخ الاحتياطي لا ينقل ملف المشروع أو الفيديو الأصلي أو ملفات المصدر المنزلة أو الكاش.

عند أول تشغيل يكون المسار الافتراضي `%USERPROFILE%\Documents\YouCut Backups`، ويمكن تغييره من الإعدادات. يُحفظ المسار المختار كتفضيل محلي. النموذج يعرض مسارات مثال للتفاعل فقط، ولا يستدعي نافذة Windows فعلية.

## الملفات المقترحة

لمشروع اسمه `Match Highlights`:

```text
Match Highlights.youcut
Match Highlights.youcut-data/
  downloads/       مصادر جرى تنزيلها من رابط
  cache/           صور مصغرة وملفات Proxy قابلة لإعادة الإنشاء

<مجلد النسخ الاحتياطي الذي يختاره المستخدم>/
  <project-id>/
    recovery/      آخر حالة استرداد ونسختان سليمتان سابقتان
```

**قرار معتمد:** تسمية مجلد البيانات بمعرّف المشروع الثابت، مثل `<project-id>.youcut-data`، بدل اسم المشروع. يظل الربط سليمًا عند تغيير اسم الملف، ويحتوي ملف `.youcut` على المعرّف نفسه. عند نقل المشروع، ينقل المستخدم الملف ومجلد البيانات معًا. إنشاء نسخة مستقلة عبر Save As ينشئ معرّفًا جديدًا لتجنب اختلاط النسخ الاحتياطية.

ملف `.youcut` هو المرجع الدائم لحالة المشروع: معرف ثابت، نسخة مخطط البيانات، أوقات الإنشاء والتعديل، مصدر الفيديو، نطاق التحليل، المقاطع، التوزيع والتتبع، وإعدادات التصدير. لا يوضع محتوى الفيديو الثنائي داخل JSON. ملف محلي يظل مرجعًا لمساره الأصلي؛ مصدر الرابط الذي ينزله التطبيق يُخزن في `downloads`. الملفات المشتقة التي يمكن إعادة بنائها تُحفظ في `cache`.

شكل JSON المقترح، مع حذف التفاصيل غير اللازمة للمثال:

```json
{
  "format": "youcut-project",
  "schemaVersion": 1,
  "projectId": "<stable-id>",
  "name": "Match Highlights",
  "createdAt": "<ISO-8601 timestamp>",
  "modifiedAt": "<ISO-8601 timestamp>",
  "source": {
    "kind": "file",
    "path": "D:/Videos/match.mp4",
    "fingerprint": { "sizeBytes": 123456, "modifiedAt": "<timestamp>" }
  },
  "analysisRange": { "startMs": 0, "endMs": 300000 },
  "clips": [],
  "export": { "container": "mp4", "aspectRatio": "9:16", "maxHeight": 1920 }
}
```

الإحداثيات تكون نسبًا من أبعاد المصدر أو مساحة الناتج، لا بكسلات المعاينة؛ ذلك يحافظ عليها عند تغيير دقة العرض. يجب أن تحتفظ المقاطع بمعرفات ثابتة وأزمنة صحيحة بالميلي ثانية، وتخزن الكاميرا وهدف التتبع والتصحيحات في حقول منفصلة.

سجلات التطبيق العامة تبقى منفصلة عن مجلد المشروع داخل مساحة بيانات YouCut المحلية للمستخدم. لا تحتوي السجلات على الفيديو، وتُنقح المسارات والروابط عند إعداد تقرير تشخيص.

## الحفظ التلقائي

تُحفظ التعديلات المستقرة تلقائيًا بعد توقف الإدخال لمدة خمس ثوانٍ، وعند الانتقال بعيدًا عن المشروع، وعند طلب إغلاقه. تغيير الوقت الجاري للمعاينة أو تقدم التحليل والتصدير لا يُكتب مع كل تحديث؛ تُحفظ فقط نقاط الحالة المفيدة، حتى لا تتضخم الملفات أو يتباطأ المحرر.

كل حفظ يمر بمراحل: إنشاء JSON كامل في ملف مؤقت بجوار `.youcut`، التحقق من بنيته، ثم استبدال الملف الرئيسي ذريًا. يحتفظ التطبيق بنسختين سليمتين سابقتين وبيانات الاسترداد داخل مجلد النسخ الاحتياطي الذي يختاره المستخدم في الإعدادات، ضمن مجلد فرعي بمعرف المشروع لتجنب تعارض الأسماء. النسخ الاحتياطية تشمل ملف المشروع وبيانات الحالة فقط، ولا تكرر الفيديوهات الأصلية أو الكاش القابل لإعادة الإنشاء. لا يعتبر واجهة المستخدم أن المشروع حُفظ إلا بعد اكتمال الاستبدال؛ عند الفشل تبقى التعديلات الحالية ظاهرة وتظهر حالة حفظ فاشل قابلة لإعادة المحاولة.

اختيار مجلد النسخ الاحتياطي وتغييره متاحان من الإعدادات. يُحفظ المسار كتفضيل محلي للتطبيق، ويُعرض للمستخدم. إذا أصبح المجلد غير متاح، يتوقف النسخ الاحتياطي ويظهر تنبيه مع خيار إعادة المحاولة أو اختيار مكان آخر؛ يظل حفظ ملف المشروع الأساسي مستقلًا ومستمرًا.

## الاستعادة بعد التعطل

عند فتح المشروع، يتحقق التطبيق من الملف الرئيسي ومخطط بياناته. إذا وجد في المجلد المحدد حالة استرداد أحدث من آخر حفظ سليم، يعرض للمستخدم وقتها وخيارات استعادة الحالة أو فتح آخر نسخة سليمة. لا يستبدل نسخة سليمة تلقائيًا ببيانات تالفة.

العمليات التي كانت تعمل أثناء التعطل تُعلّم بأنها توقفت بشكل غير متوقع. لا يعاد تشغيل تحليل أو تصدير تلقائيًا؛ يختار المستخدم إعادة المحاولة. ملفات التصدير المؤقتة تظل متاحة خلال إعادة المحاولة وفق سياسة الملفات المؤقتة المعتمدة، وتُحذف بعد النجاح أو الإلغاء النهائي.

## النقل وإعادة الربط

نقل ملف `.youcut` ومجلد `.youcut-data` معًا ينقل بيانات المشروع المملوكة للتطبيق. مجلد النسخ الاحتياطي منفصل ويختاره المستخدم من الإعدادات؛ لا ينتقل تلقائيًا مع ملف المشروع. يظل ملف المصدر المحلي خارج الحزمة لتجنب نسخه؛ إن تغير مساره يطلب التطبيق من المستخدم تحديده مجددًا، ثم يتحقق من الملف قبل إعادة الربط. إذا فُقد مجلد البيانات، يحاول التطبيق فتح ملف المشروع وإعادة بناء الكاش، ويعرض بوضوح أن تنزيلات المصدر أو نقاط الاستعادة غير المتاحة قد تحتاج إلى إعادة إنشاء.

## التوافق والتحقق

يحمل كل ملف `schemaVersion` مستقلًا عن إصدار التطبيق. عند فتح مخطط أقدم، يُجرى ترحيل على نسخة مؤقتة، ثم تحقق، ولا يُستبدل الملف الأصلي إلا بعد نجاح الترحيل والحفظ. الملف غير الصالح يبقى كما هو وتظهر رسالة مع خيار إنشاء تقرير تشخيص.

الحد الأدنى للتحقق قبل اعتماد التنفيذ: حفظ وإغلاق وإعادة فتح دون فقد التعديلات، قتل التطبيق أثناء الحفظ ثم فتح نسخة سليمة أو استردادها، فتح مشروع بعد نقله مع إعادة ربط المصدر، ترحيل نسخة مخطط أقدم، والتأكد من بقاء المصدر الأصلي دون تعديل.

## نقاط تحتاج اعتمادًا قبل التنفيذ

- تحديد مكان التنزيلات والكاش وحد الاحتفاظ النهائي بعد قياس أحجام ملفات 4K وFull HD.
- مراجعة مخطط JSON بعد تنفيذ نموذج التحقق والترحيل.
